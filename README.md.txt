# 🖐️ Real-Time Sign Language to Text & Speech System

## 📖 Project Overview

This project is a Real-Time Sign Language Recognition System that converts hand gestures (A–Z alphabets) into:

- ✅ Text (Words & Sentences)
- ✅ Speech (Audio Output)

The system uses:
- OpenCV for real-time hand capture
- Convolutional Neural Networks (CNN) for alphabet classification
- Sentence Builder logic for word formation
- Text-to-Speech (pyttsx3) for voice output

This is an end-to-end AI-based application combining Computer Vision, Deep Learning, and Speech Synthesis.

---

## 🎯 Features

- 📷 Real-time webcam hand gesture detection
- 🧠 CNN-based alphabet classification (A–Z)
- 🔤 Word & sentence formation
- 🔊 Speech output
- 💾 Option to download generated speech as `.wav`
- 🖥️ Clean UI with control panel
- 🔁 Supports left and right hand gestures
